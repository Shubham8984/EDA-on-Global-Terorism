# 🌍 Global Terrorism Dataset - Exploratory Data Analysis (EDA)

This project analyzes the **Global Terrorism Database (GTD)** to uncover trends, patterns, and insights in worldwide terrorist activities from 1970 to 2017.

---

## 📌 Key Insights

- **Top Countries Affected**: Iraq, Afghanistan, Pakistan, and India.
- **Top Cities Globally**: Baghdad, Karachi, Lima, Mosul.
- **Top 5 Indian Cities**: Srinagar, Imphal, New Delhi, Amritsar, Seapore.
- **Attack Trends in India**: Rise from late 1980s, peak in 2016, declining since.
- **Global Attack Trends**: Increase from 1980s, peak in 2014, then decline.
- **Common Attack Types**: Bombings, Armed Assaults, Assassinations.
- **Deadliest Terror Groups**: Taliban, ISIL, Boko Haram.
- **Most Affected Region**: Middle East and North Africa.

---
